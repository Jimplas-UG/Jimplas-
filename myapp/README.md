# Moved

The app was split into two folders:

- **Frontend (Expo UI):** `../frontend/`
- **Backend (engine + API + backtests):** `../backend/`

Use `cd ../frontend && npm start` for the mobile app, and `cd ../backend && npm run desk-api` for the strategy server.

This `myapp/` folder is kept only for leftover `node_modules` until you delete it after reinstalling in `frontend/`.
